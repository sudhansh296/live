Hivo Live — Page 2: Profile setup

Design preview only (HTML). Shown right after the first login. The real screens will be built in Jetpack Compose.
What is asked: display name (2–30 characters), unique @username, date of birth (18+ is checked by the server, not the app), country (guessed from your phone, you can change it), and an optional photo.
Privacy: the birthday is never sent to other users. Photos are resized on the server and location data inside the photo is removed.
Under 18: the server refuses and does not let the same account retry with a different date.
Also handled (not drawn): name too short, unsupported photo type, photo too large, no internet, and username checked live while typing (with a short delay so it is not spammed).
